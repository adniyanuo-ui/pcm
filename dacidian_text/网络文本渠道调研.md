# 《中医方剂大辞典》及相关方剂文本渠道调研

## 调研结论

截至 2026-09-03，没有检索到一个能够同时满足以下条件的下载渠道：明确获得授权、可以直接批量下载、完整覆盖《中医方剂大辞典》96592 首方剂、保留全字段正文和出处、允许用于后续产品开发。

“在网络上能搜索或阅读”不等于“已进入公有领域”或“允许批量复制和商用”。《中医方剂大辞典》第 1 册由人民卫生出版社于 1993 年出版；如果未来将全文随商业产品部署，应优先确认出版社或数据库提供方的数据使用许可。

当前最稳妥的技术路线是：保留本地 PDF OCR 形成的可追溯底稿，同时联系下列数据库提供方，询问是否能取得正式 API、批量导出或机构授权。如果取得授权，可将其结构化文本用作 OCR 校勘源和补充源。

## 候选渠道

### 1. 中国方剂数据库

- 地址：http://cintmed.cintcm.com/cintmed/html/zyfj.jsp
- 公开介绍称收录 710 余种古籍及现代文献中的 84464 首方剂；
- 字段包括方名、别名、处方来源、药物组成、功效、主治、禁忌、药理作用和制备方法；
- 国家科技资源开放共享目录也曾列出该数据库；
- 优点：机构背景和字段与本项目较匹配；
- 局限：当前站点证书配置异常，未发现公开批量下载或正式开放 API 文档；收录量也不等同于《中医方剂大辞典》的 96592 首。

建议：优先联系中国中医科学院中医药信息研究所，询问数据授权与批量接口。这是来源可靠性优先的选择。

## 2. 博览医书—中西医百科数据平台

- 公开的高校图书馆试用说明称其收录约 95260 个方剂，并整合包括《中药方剂大辞典》等多部辞典；
- 方剂字段包括异名、组成、功用、用法、主治、加减和宜忌等；
- 优点：规模最接近全书，且已经条目化，若能获得正式授权会比 OCR 容易很多；
- 局限：属于机构数据库/试用或订阅服务，没有发现开放全量下载；公开页面有时将书名写作《中药方剂大辞典》，需要向提供方确认是否确为本书以及覆盖范围。

建议：这是“最值得询价和申请授权”的渠道，重点询问 API、批量 JSON/Excel、商业产品内检索权和来源页码。

## 3. 摩熵数科中医药方剂 API

- 地址：https://open.bcpmdata.com/api/163.html
- 页面宣称超过 100000 条中医经典方剂和临床复方；
- API 示例字段非常完整，包括方名、异名、出处、组成、制法、用法、功用、主治、宜忌、加减、方解、附方、方论、临证举例和现代研究；
- 优点：从软件接入角度最省力，字段与本项目目标高度一致；
- 局限：商业询价接口，不是公开全量文本；需要确认数据来源、与《中医方剂大辞典》的重合度、引用页码、更新机制及产品使用授权。

建议：可申请少量样例，与本次 OCR 的第 1 册按方号/方名抽样比对后再决定是否购买。

## 4. 人民卫生出版社《中医方剂大辞典精选本》

- 出版社商品页：https://www.pmphmall.com/gdsdetail/62033-63032
- 从 96592 首中精选 15430 首；
- 优点：出版社正式版本，适合核心常用方和人工校勘；
- 局限：不是全本，也未发现开放的结构化文本接口。

## 5. 公开古籍全文站点

中国哲学书电子化计划、维基文库、公开古籍站及各原始方书的数字化版本，可用于回查《圣惠方》《普济方》《鸡峰普济方》《寿亲养老》等原始出处。例如本次已用公开原文交叉确认“一醉乌”“三肉臛”“小荜澄茄煎”等疑难字。

优点是部分古籍属于公共领域、文本可搜索；缺点是它们不是已经汇总好的《中医方剂大辞典》，版本、断句和 OCR 质量不一，无法直接替代全书，只适合来源校验和补校。

## 6. 开源或科研数据集

- 齐鲁工业大学与山东中医药大学附属医院公开的中医辨证辨病及处方推荐任务，只有约 1500 条脱敏病历，适合后续流程评测，不是方剂大辞典文本；
- 一些 GitHub/开放平台提供数百至数千首方剂，许可证和来源差异很大；
- 香港浸会大学中药方剂图像数据库可网页查询方名、组成、功用和主治，但未发现覆盖九万余方的开放批量数据。

这些资源可以作为补充和测试集，不能代替本书完整文本。

## 推荐顺序

1. 先联系“博览医书”和“中国方剂数据库”，询问全量授权、API/批量导出、字段来源和商业使用条件；
2. 同时向摩熵数科申请样例，用第 1 册的 9634 个条目做覆盖率与正确率比对；
3. 在授权结果明确前，保留当前本地 OCR 成果，不从不明网盘、付费下载站或无许可证仓库抓取全量文本；
4. 若没有可接受的正式文本授权，再按当前可断点、可审计流程依次转换第 2—11 册；
5. 无论采用哪个外部渠道，都保留方名、出处、原书页码和版本信息，避免形成无法回溯来源的“混合方剂库”。
