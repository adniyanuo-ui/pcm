# 三志堂焦虑抑郁管理微信小程序隐私政策

## 一、信息收集范围

### （一）基础注册信息



*   **必要信息**：姓名、年龄、性别、身高、体重、婚姻状况、手机号（用于 **账号注册、身份核验、中医辨证分析及服务沟通** ，其中 **性别、身高、体重专项用于体质分型及食疗方案精准适配** ）；

*   **微信授权信息**：微信昵称、头像（仅用于账号展示，不用于其他用途）。

### （二）健康评估信息



*   用户主动提供的 **情绪状态描述、身体症状表现、既往病史** 等健康相关信息；

*   小程序通过中医辨证模型生成的 **体质分析数据**（基于注册信息及用户反馈）。

### （三）设备与使用信息



*   设备型号、操作系统版本、IP 地址（用于服务兼容性优化、异常登录检测）；

*   小程序使用日志（含功能访问记录、操作时间等，用于服务体验改进）。

## 二、信息使用规则

### （一）核心用途



1.  基于 **姓名、年龄、性别、身高、体重** 及健康信息，提供 **个性化中医情志、经络、食疗调理方案**（健康管理建议性质）；

2.  通过手机号发送 **方案提醒、健康科普资讯**（用户可回复 “退订” 停止推送）；

3.  用于 **账号安全验证、异常行为监测** ，保障服务合规性；

4.  若涉及 **医学研究项目**（符合公司经营范围 “医学研究和试验发展”），需单独获得用户书面同意，且数据将做匿名化处理。

### （二）信息共享限制



1.  **禁止擅自共享**：未经用户明确书面同意，不向任何第三方共享 **姓名、年龄、性别、身高、体重** 及健康隐私信息；

2.  **必要共享场景**：仅向平台签约 **中医健康管理顾问** 提供必要信息（用于方案制定），顾问需签署《保密协议》；或配合司法机关依法调取信息。

### （三）数据存储期限



*   **注册及健康数据**：账号存续期间保留，账号注销后 **永久删除**（不可恢复）；

*   **设备与使用日志**：保留期限为 **1 年** ，到期后自动匿名化处理。

## 三、信息安全保障

### （一）技术措施



*   采用 **SSL 加密协议** 传输用户数据，防止传输过程泄露；

*   健康信息存储采用 **AES 加密数据库** ，限制内部人员访问权限；

*   定期开展 **安全漏洞扫描、数据备份** ，防范信息泄露风险。

### （二）管理规范



*   建立《用户信息安全管理制度》，员工入职需签署 **保密承诺书** ；

*   访问用户敏感信息（如健康数据）需经 **多层审批流程** ；

*   若发生数据安全事件，将立即启动应急预案，并 **48 小时内通知受影响用户** 。

### （一）信息查询与更正



*   路径：小程序 “我的 - 健康档案” → 可随时查看 **姓名、年龄、性别、身高、体重** 及健康数据；

*   更正：发现信息错误，可联系客服（`zzd@sanzhit.com`）申请修正， **3 个工作日内反馈处理结果** 。

*   效果：账号注销后， **所有个人信息、健康数据永久删除** ，无法恢复。

## 五、特殊条款

### （一）未成年人保护



*   **使用限制**：未满 16 周岁用户使用本服务，需 **监护人协助注册** 并确认同意；

*   **信息管理**：监护人可联系客服查询、更正未成年人的 **姓名、年龄、性别** 等信息，平台将严格核验监护人身份。

### （二）敏感信息处理



*   **敏感信息定义**： **姓名、年龄、性别、身高、体重** 及健康信息均属于敏感个人信息，平台仅在 **“健康管理咨询” 必要范围内收集** ；

*   **额外用途授权**：若用于医学研究等超出服务范围的用途，需 **单独获得用户书面同意** 。

### （三）政策更新



*   公告方式：小程序首页弹窗或公告栏发布更新通知；

*   生效规则：涉及用户核心权利的修改，提前 **30 日公告** ；继续使用服务即视为接受更新后的政策。
